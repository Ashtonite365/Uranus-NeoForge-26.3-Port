# Uranus NeoForge 26.3 Port (UNOFFICIAL, BETA)

**Version:** 3.0-alpha.1-port.1-beta · **Minecraft:** 26.3 · **Loader:** NeoForge 26.3.0.76+ · **Mod id:** `uranus_port263` (content namespace still `uranus`)

This is an unofficial port of Uranus by IAFEnvoy to Minecraft 26.3 on NeoForge. A library containing an animation engine, object helper and so on (partly based on LLibrary and Citadel).
It is **beta**: expect bugs. It is not affiliated with or supported by IAFEnvoy, so please don't report issues from this port upstream.
It is a library dependency of the Ice and Fire CE 26.3 port. Don't install it alongside the official Uranus.
